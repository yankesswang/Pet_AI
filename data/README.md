# VetLink AI — 資料層 (Data Layer)

本目錄負責把**農業部動物用藥開放資料**轉成 Evidence Gate 可以直接判斷的
「產品證據卡」(product evidence card)，並產出後端 Demo 用的小型子集。

> 本資料層只做擷取、清理與正規化，**不做任何醫療判斷或用藥建議**。
> 規則判斷屬於 `backend/app/engine/`，不在本目錄範圍。

### API 分頁行為（重要）

直接呼叫 API 只會回傳 **9,999 筆**（被截斷），並非全量。
必須以 OData 參數分頁才能取得完整資料：

```
?$skip=0&$top=2000
?$skip=2000&$top=2000
...
```

`fetch_moa.py` 以每頁 2,000 筆分 7 頁取得全部 13,739 筆。

### 去重

原始回應含 **1 筆重複的許可證字號**，以 `許可證字號` 為主鍵去重後為 13,738 筆。

### 授權與標示

* 本專案依政府資料開放授權條款使用上述資料，並於畫面與輸出中標示來源機關。
* 資料為**許可證底座**，僅涵蓋許可證字號、品名、業者、劑型、成分、適應症與效期。
* 公開資料**不足以**支撐完整的禁忌症、副作用、注意事項與最新版仿單問答；
  這些欄位在系統中必須標示為「待企業文件確認」，不得由模型自行補齊。

## 2. 執行方式

```bash
cd data

python3 fetch_moa.py          # 1. 擷取全量原始資料（可續傳）
python3 normalize.py          # 2. 正規化成產品證據卡
python3 build_demo_subset.py  # 3. 產出後端 Demo 子集
```

### 相依套件 (requirements)

僅需 Python 3.8+ 標準函式庫，另**可選**用 `requests`：

```
requests>=2.28    # 選用；未安裝時自動改用標準庫 urllib
```

`fetch_moa.py` 會先嘗試 `import requests`，失敗則自動退回 `urllib.request`，
因此在純標準庫環境下也能執行。

### 擷取行為

* 每頁之間預設延遲 **1.5 秒**，對公開 API 保持禮貌。
* 逾時／連線錯誤採指數退避重試，最多 4 次。
* **可續傳**：每頁結果快取於 `raw/.pages/`，重跑只補抓缺頁；`--force` 可清除快取重抓。
* **冪等**：以許可證字號去重並固定排序，重複執行產生相同輸出。

## 4. 民國紀年轉換 (ROC → 西元)

原始資料的日期皆為民國紀年文字，**換算公式：民國年 + 1911 = 西元年**。

### 有效期間 (`有效期間` → `expiry_date_iso`)

| 原始值 | 轉換結果 | 說明 |
| --- | --- | --- |
| `至120年04月30日止` | `2031-04-30` | 仍有效 |
| `至82年01月01日止(已失效)` | `1993-01-01` | 帶失效標記 |
| `""`（空字串） | `null` | 999 筆，效期不明 |

### 核發日期 (`核發日期` → `issue_date_iso`)

| 原始值 | 轉換結果 |
| --- | --- |
| `中華民國110年09月13日` | `2021-09-13` |
| `""`（空字串） | `null` |
| `中華民國0000301`（格式毀損，3 筆） | `null`（不做猜測） |

共 13,720 筆成功解析，18 筆無法解析（15 筆為空、3 筆格式毀損）。

### 失效判定 `is_expired`

**同時採信兩種獨立訊號**，任一成立即視為失效：

1. `expired_by_marker` — 文字含「(已失效)」標記
2. `expired_by_date` — 換算後的到期日 < 基準日（Demo 固定為 **2026-08-19**）

這兩條路徑不可互相取代。實測全量資料：

| 判定 | 筆數 |
| --- | ---: |
| 已失效（合計） | **9,120** |
| ├ 帶「(已失效)」標記 | 7,617 |
| └ 僅日期已過（來源未標記） | **1,503** |
| 仍有效 | 4,618 |
| 效期不明（無日期且無標記） | 999 |

> 有 1,503 筆許可證**已經過期，但來源沒有任何失效標記**，
> 只有換算民國紀年並比對基準日才抓得到。這正是文件效期閘門的價值所在：
> 若只信任來源的「(已失效)」欄位，這 1,503 筆過期文件會被當成有效證據引用。

基準日可用 `--as-of YYYY-MM-DD` 覆寫，方便展示「同一份資料在不同時間點的判定差異」。

## 5. 其他資料清理

### 成分欄位的 HTML

**3,899 筆**的 `成分` 含原始 HTML（`<div>`、`<sub>`、`&nbsp;` 等），需清成純文字。
清理時**保留化學式語義**：`<sub>` 只脫標籤不換行，避免下標被拆行。

```
原始: <div>AMOXICILLIN (散劑)；C<sub>16</sub>H<sub>19</sub>N<sub>3</sub>O<sub>5</sub>S·3H<sub>2</sub>O&nbsp;</div>
清理: AMOXICILLIN (散劑)；C16H19N3O5S·3H2O
```

### 適應症的物種解析

`效能(適應症)` 是混合多物種的長段自由文字（例：`豬：…雞：…鰻形目：…`），
`species` 欄位由此解析出物種清單，支援：
犬（含「狗」）、貓、豬、雞、火雞、鴨、鵝、鴿、牛、羊、馬、兔、鹿、魚（含鰻／鮭／鱒／鱸／鯛／鱺／石斑）、蝦、蜂、猴、鳥。

**假陽性排除**：疾病名稱含物種字但不代表適用該物種，比對前先遮蔽這些詞：

| 詞彙 | 誤判 | 實際 |
| --- | --- | --- |
| 雞**馬**立克病 | 馬 | 雞的疾病（74 筆已正確排除） |
| 假性狂**犬**病 | 犬 | 豬的疾病 |
| **牛**蒡、**羊**毛脂、**魚**肝油 | 牛／羊／魚 | 成分名稱 |

實測物種分布（全量）：豬 5,710、雞 4,646、牛 1,866、犬 1,391、馬 758、貓 708、
羊 668、火雞 621、魚 403、鴨 392、鴿 262、兔 86。
3,915 筆無法解析出物種（多為製劑原料、消毒劑等非特定物種用品）。

`is_companion_animal` 於 `犬` 或 `貓` 出現時為 `true`：全量 **1,470** 筆
（有效 807 / 失效 663）。

### 其他

* 適應症為空：17 筆
* 外銷專用（`外銷專用 = 是`）：236 筆

## 6. 產品證據卡欄位

每筆記錄的完整欄位如下。`doc_id` / `version` / `source_url` / `fetched_at`
是**回答護照 (Answer Passport)** 與 **Impact Replay** 的溯源基礎。

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| `doc_id` | str | 穩定文件 ID，格式 `MOA-AD-<許可證數字>` |
| `licence_no` | str | 許可證字號（主鍵） |
| `name_zh` / `name_en` | str | 中／英文品名 |
| `company` / `company_address` | str | 業者名稱／地址 |
| `manufacturer` / `manufacturer_address` | str | 製造廠名稱／地址 |
| `dosage_form` / `packaging` | str | 劑型／包裝 |
| `ingredients_clean` | str | 成分（HTML 已剝除） |
| `ingredients_had_html` | bool | 原始成分是否含 HTML |
| `indications_raw` | str | 效能（適應症）純文字 |
| `species` | list[str] | 解析出的物種清單 |
| `species_slugs` | list[str] | 物種英文代碼（dog / cat / pig …） |
| `is_companion_animal` | bool | 是否為犬貓適用 |
| `export_only` | bool | 是否外銷專用 |
| `issue_date_iso` / `issue_date_raw` | str\|null | 核發日期（ISO ／ 原始民國文字） |
| `expiry_date_iso` / `expiry_date_raw` | str\|null | 有效期間（ISO ／ 原始民國文字） |
| `is_expired` | bool | 是否失效（標記 OR 日期，任一成立） |
| `expired_by_marker` | bool | 來源帶「(已失效)」標記 |
| `expired_by_date` | bool | 到期日早於基準日 |
| `expiry_unknown` | bool | 無日期且無標記，效期不明 |
| `version` | str | 內容指紋版本號（`v1.<sha256前12碼>`） |
| `schema_version` | str | 資料結構版本 |
| `source_url` / `source_agency` / `source_type` | str | 來源溯源 |
| `fetched_at` / `normalized_at` / `evaluated_as_of` | str | 擷取／正規化／效期判定基準時間 |

`version` 為原始欄位內容的雜湊：來源任何欄位變動都會改變版本號，
可作為 **Impact Replay** 判斷「哪些歷史回答引用了已變更文件」的觸發條件。

### 中化內部仿單「不」在本資料層範圍

依提案第 13.1 節的資料策略，本 Demo **不依賴中化內部資料**：

* 本目錄所有欄位**皆來自政府公開資料**，未虛構任何品項、成分或適應症。
* **中化內部核准仿單、產品主檔、標籤、通路與銷售資料一律無法取得**，
  列為**入圍後的正式介接項目**，不作為 Demo 成立的前提。
* 公開資料沒有的內容（完整禁忌、警語、不良反應、處方／非處方分類、
  停售與召回狀態）必須標示為「待企業文件確認」，不得自行補齊。

正式導入後由中化提供的每份文件需具備：
`文件 ID、版本、生效日、失效日、來源單位、審核人、審核狀態、更新時間`，
以銜接本資料層已預留的 `doc_id` / `version` / 效期欄位。

## 9. 已知限制

1. **公開資料只是許可證底座**，不含完整仿單內容，無法單獨支撐用藥問答。
2. 999 筆效期不明（無日期也無標記），系統應視為「證據不足」而非「有效」。
3. 3,915 筆無法解析物種，多為製劑原料與環境消毒劑，非特定動物用品。
4. 物種解析為關鍵字規則比對，已排除已知假陽性，但無法保證涵蓋所有罕見寫法。
5. 適應症未再細分至「症狀／適應症」結構化欄位，僅保留原文供主張級引用。
6. 官方標示每週更新，`fetched_at` 之後的變更需重跑 `fetch_moa.py` 才會反映。
